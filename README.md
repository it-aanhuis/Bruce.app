# Bruce.app

⚠️ **NOTE:** This project is **currently under construction**. The web app is not fully functional yet.

---

## About this project

This repository contains an **HTML-based web app** intended to interact with Bruce firmware modules.  
The goal is to provide an easy-to-use interface to control Bruce modules from a browser or mobile device.

**Status:** In development / proof of concept.

## Usage

1. Clone or download this repository.  
2. Open `index.html` via a local web server or host it online (e.g., via GitHub Pages).  
3. Connect to your Bruce modules using the correct IP address (AP or Station mode).

> ⚠️ Currently, the web app is a **prototype** and mainly for testing purposes.
